# 📘 ShortcutList Component

A reusable React component for Docusaurus that renders a list of keyboard shortcuts as `<kbd>` chips paired with a description. It replaces hand-typed `<kbd>` bullet lists, giving a consistent visual separator between keys instead of a hardcoded `+` or `and`.

It is not a replacement for `StepsCard`: `StepsCard` remains the right choice for sequential, textual reference lists (flag → explanation). `ShortcutList` is specifically for keyboard shortcut references (keys → description).

## 🚀 Features

- ✅ Renders each key as a native `<kbd>` chip, reusing the site's global `kbd` styling
- ➕ Automatic visual `+` separator between keys — no hardcoded separators in content
- 🛠️ PropTypes for type safety

## 🧪 Usage

```mdx
<ShortcutList
  items={[
    { keys: ["Ctrl", "A"], desc: "Open a secondary screen listing actions." },
    { keys: ["E"], desc: "Open an editor to modify the configuration file." },
  ]}
/>
```

## 🧾 Props

| Prop    | Type                                      | Required | Default | Description                 |
| ------- | ----------------------------------------- | -------- | ------- | --------------------------- |
| `items` | `Array<{ keys: string[], desc: string }>` | ✅       | —       | List of shortcuts to render |
