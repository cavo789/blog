# 📋 CopyAsMarkdown Component

The `CopyAsMarkdown` component renders a "Copy as Markdown" button and a "View raw" link in a
Docusaurus blog post header. It lets a reader — or an LLM they paste the URL into — get the
article's full plain-text content without React, JSX, or any collapsed accordion the HTML page
hides by default.

## ✨ Features

- 📋 One-click copy of the article's plain-Markdown mirror to the clipboard
- 🔗 "View raw" link that opens the same mirror in a new tab
- 🧠 Three visual states — idle, copied, error — with automatic reset after 2 seconds
- 🪶 No dependencies beyond `react` and `prop-types`
- 🧯 Fails gracefully: a missing mirror (e.g. during `yarn start`) shows "Could not copy"
  instead of throwing

## 📦 Requirement: a plain-Markdown mirror

This component does not generate any Markdown itself — it only fetches and copies. It expects a
plain-text mirror of the current page to be reachable at `<permalink>.md` (e.g.
`/blog/my-post` → `/blog/my-post.md`).

On this site that mirror is written at build time by `plugins/markdown-export-plugin`, which
degrades the MDX source (custom components, `<Terminal>`, `<Snippet>`, …) down to plain
Markdown during `postBuild`. Without an equivalent mirror in place, the button always ends in
the "Could not copy" state — this is expected, not a bug, and is exactly what happens on
`yarn start`, since the mirror only exists in a production build.

> **Reproducing this on your own blog:** see [Add a "Copy as Markdown" Button to Your Docusaurus
> Blog](https://www.avonture.be/blog/docusaurus-copy-as-markdown) for a full, step-by-step
> walkthrough — including a minimal mirror-generating plugin you can adapt.

## 🧪 Usage

```jsx
import CopyAsMarkdown from "@site/src/components/CopyAsMarkdown";

<CopyAsMarkdown metadata={metadata} />;
```

`metadata` is the object Docusaurus's `useBlogPost()` hook exposes to every blog post component.
Only `metadata.permalink` is read.

## 🧾 Props

| Prop                 | Type   | Required | Default | Description                                           |
| -------------------- | ------ | -------- | ------- | ----------------------------------------------------- |
| `metadata`           | object | ✅       | —       | Docusaurus blog post metadata                         |
| `metadata.permalink` | string | ✅       | —       | URL path of the current post; `.md` is appended to it |

## 🔀 Behavior

| State     | Button label        | Trigger                                                  |
| --------- | ------------------- | -------------------------------------------------------- |
| `idle`    | 📋 Copy as Markdown | Default state, and 2 s after `copied` or `error`         |
| `copying` | 📋 Copy as Markdown | While the `fetch` for the mirror is in flight (disabled) |
| `copied`  | ✓ Copied            | Fetch + `navigator.clipboard.writeText` both succeeded   |
| `error`   | Could not copy      | Fetch failed (e.g. 404) or the Clipboard API threw       |

## 🎨 Styling

Two elements, both styled via `styles.module.css` and Infima CSS variables — no hardcoded
colors, so the button adapts to light mode, dark mode, or any custom Docusaurus theme:

- `.copyBtn` — bordered, transparent button
- `.rawLink` — plain text link for "View raw"

## 🧩 Where it's wired in

This component is rendered by `src/theme/BlogPostItem/index.js`, which passes it down to
`src/theme/BlogPostItem/Header` — only when `isBlogPostPage` is `true`, so it never shows up on
a list-view card, only on the article itself.
