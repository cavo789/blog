# Project Charter

## Scope

The project covers migration of the customer database and the billing system to the new CRM platform.

## Timeline

Estimated duration: 6 months, starting March 2027, with a mid-project review after month 3.

## Budget

Estimated budget: EUR 130,000, including a 15% contingency reserve.

## Risks

Key risk: billing system migration depends on the vendor's API becoming available by month 2.
