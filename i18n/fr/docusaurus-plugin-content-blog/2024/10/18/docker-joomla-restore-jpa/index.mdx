<TLDR>
  Ce guide explique comment restaurer un site Joomla en local en combinant
  Docker, une archive Akeeba Backup et l'utilitaire Akeeba Kickstart. On
  configure un environnement sur mesure avec PHP et Apache, puis on lance une
  simple commande d'import pour déployer les fichiers et les containers
  nécessaires. Le processus se termine dans le navigateur, via l'assistant
  Kickstart, pour finaliser la connexion à la base de données et la restauration
  du site.
</TLDR>

Dans les articles précédents ([Partie 1](/blog/docker-joomla) et [Partie 2](/blog/docker-joomla-part-2)), nous avons vu comment créer un site Joomla de zéro avec Docker : récupérer Joomla, PHP, Apache et MySQL depuis Docker Hub et faire un peu de magie pour obtenir un site local tout neuf sur `http://127.0.0.1:8080`.

Dans cet article, nous allons voir comment restaurer sur notre machine une sauvegarde créée grâce à l'excellent composant **[Akeeba Backup](https://www.akeeba.com/products/akeeba-backup.html)**.

Nous allons réutiliser certains fichiers de la [Partie 2](/blog/docker-joomla-part-2) et les adapter.

À la fin, nous aurons une commande `make import` qui démarrera **[Akeeba Kickstart](https://www.akeeba.com/download.html#kickstart)**.

## Pourquoi ça fonctionne {#why-it-works}

- Nous réutilisons le même trio `compose.yaml`/`.env`/`makefile` que dans la [Partie 2](/blog/docker-joomla-part-2), donc rien de neuf à apprendre là-dessus.
- Le seul vrai changement : comme la sauvegarde **est** déjà un site Joomla complet, les containers n'ont besoin que de PHP et Apache, pas d'une image Joomla fraîche — la base de données est reconstruite depuis la sauvegarde par Akeeba Kickstart, et non par l'installateur de Joomla.

Placez également une sauvegarde de votre site existant dans le même dossier. Par souci de standardisation, nommez ce fichier `backup.jpa`.

Pour être plus explicite : rendez-vous sur votre site Joomla existant et, avec Akeeba Backup, créez une sauvegarde (format de fichier : `.jpa`) puis téléchargez-la. Renommez le fichier de sauvegarde ainsi : `backup.jpa`.

Enfin, il nous faut aussi deux fichiers provenant d'**[Akeeba Kickstart](https://www.akeeba.com/download.html#kickstart)**.

Les deux fichiers dont nous avons besoin s'appellent `en-GB.kickstart.ini` et `kickstart.php`.

## Lancer le processus d'importation {#run-the-importation-process}

Voilà, vous avez copié pas mal de fichiers. Il est temps de restaurer votre site.

Pour les utilisateurs Linux, profitez simplement de `GNU Make` et lancez l'instruction `make import`.

Pour Windows (Powershell ou DOS), lancez ces commandes :

<Terminal typewriter title="Powershell">
  mkdir db_data mkdir joomla_data copy en-GB.kickstart.ini joomla_data\ copy
  kickstart.php joomla_data\ copy backup.jpa joomla_data\ docker compose up
  --detach
</Terminal>

Dans les deux cas (Linux et Windows), vous obtiendrez une sortie de ce genre dans la console :

<Terminal typewriter source="./files/terminal-1.txt" />

Une fois terminé, ouvrez votre navigateur et rendez-vous sur `http://127.0.0.1:8080/kickstart.php` pour démarrer la restauration de votre site avec l'assistant **Akeeba Kickstart** — les écrans montrés en haut de cet article.

Lorsque vous devez renseigner les informations de base de données, référez-vous à ce qui s'est affiché dans votre console.

Poursuivez la restauration comme d'habitude ; fermez la fenêtre quand Akeeba Kickstart le demande, puis cliquez sur le bouton _Clean Up_ ; ensuite sur _Visit your site's frontend_ et profitez.

<AlertBox variant="info">
Si vous avez utilisé le site de démo fourni, le compte admin est **joomla** et son mot de passe est **joomla@secured**.

</AlertBox>

## Conclusion {#conclusion}

Comme nous venons de le voir, restaurer un site Joomla en local est devenu vraiment simple.

Il suffit de récupérer quelques fichiers de configuration, et seul celui nommé `.env` doit être mis à jour avec les versions de PHP et MySQL utilisées sur votre site de production.

Vous téléchargez la sauvegarde locale de votre site et, avec une seule commande (`make import`), votre site est restauré.

<Terminal typewriter>$ make import</Terminal>

Peu importe la version de Joomla ou de MySQL que vous utilisez.

Simple comme bonjour, non ?
