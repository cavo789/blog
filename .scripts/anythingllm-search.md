# Documentation: AnythingLLM Blog Search

## Overview

The `anythingllm-search.sh` script asks the AnythingLLM `blog` workspace a question in plain
English (or French) and prints the answer followed by the articles behind it, as clickable links.

Index first with `.scripts/anythingllm-index.sh` — this script only reads.

## Two answers, on purpose

Each run prints **two** lists, because neither alone is trustworthy:

| Section | Mechanism | Strength | Weakness |
| :--- | :--- | :--- | :--- |
| 📚 **Sources the answer was built from** | Vector similarity, capped at the workspace's `topN` | Finds articles that never use your wording | Never exhaustive — a couple of long articles can fill every slot |
| 🔎 **Exact frontmatter matches** | `grep` over `title` / `slug` / `description` / `mainTag` / tags | Complete and exact | Misses anything phrased differently |

This matters in practice: asked which articles cover Joomla, vector search names 3 while the blog
has 9 that mention it in their frontmatter. Raising `topN` from 20 to 60 added exactly one.
Retrieval ranks by similarity; it does not enumerate.

Keyword extraction for the `grep` pass drops function words (English and French), then drops any
surviving word matching more than 10% of the blog — so "docker" is discarded as too broad while
"joomla" survives. That rarity test is what keeps the list usable without a per-language
dictionary.

Dates and formatting come from the workspace system prompt, not from this script — see
[anythingllm-index.md](anythingllm-index.md).

## Implementation notes

- **`mode: "query"`** confines the model to retrieved documents. `"chat"` lets it answer from its
  own general knowledge, which is how you get confidently described articles that don't exist.
- **A random `sessionId` per call.** Without one, every query lands in the workspace's default
  thread and the model reads its own earlier answers as context — one wrong answer then repeats
  itself for every later question, even after the underlying retrieval has been fixed. This cost
  a real debugging detour; keep it.
- **OSC 8 hyperlinks** make each title clickable in VS Code's terminal and Windows Terminal. When
  stdout is not a TTY the script falls back to printing bare URLs.

## Prerequisites

Identical to `anythingllm-index.sh` — see [anythingllm-index.md](anythingllm-index.md) for the
API key, URL auto-detection and workspace requirements. Additionally, the workspace must already
contain embedded documents.

## How to Use

```bash
ai-search which articles cover docker?              # devcontainer shell
.scripts/anythingllm-search.sh Ai-je du contenu sur joomla?
```
